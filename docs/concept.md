# Концепция продукта

## Анализ рынка
Мы проанализировали существующие решения и выявили их ограничения:

| Продукт | Цена | Ключевые функции | Ограничения |
| :--- | :--- | :--- | :--- |
| **PETLIBRO Granary WiFi** | ~7 300 ₽ | Wi-Fi, приложение, 5 л, резервное питание | Только сухой корм; порции в мл/объеме |
| **Xiaomi Smart Pet Food Feeder** | ~10 000 ₽ | Mi Home, дозирование, контроль уровня | Сухой корм 5-12 мм; привязка к экосистеме |
| **SureFeed Microchip Feeder** | 14 000 - 17 000 ₽ | RFID/микрочип, контроль доступа | Не выдает корм автоматически по расписанию |
| **PETKIT Fresh Element Solo** | ~5 800 ₽ | Приложение, расписание, 12 порций | Нет полноценного контроля факта съедания |

**Наше преимущество:** Мы делаем ставку на точность (датчик веса) и доступность, убирая избыточные функции (например, камеру), которые удорожают продукт.

## Как это работает

| Этап | Действие | Результат |
| :--- | :--- | :--- |
| **1. Настройка** | Владелец задает расписание и размер порции через приложение | План кормления сохраняется в памяти устройства |
| **2. Срабатывание** | RTC (часы реального времени) будит контроллер | Устройство готовит дозатор к работе |
| **3. Выдача** | Мотор открывает дозирующий механизм | Корм попадает в миску |
| **4. Контроль** | Датчик веса проверяет изменение массы | Событие «порция выдана» записывается в журнал |
| **5. Эскалация** | Если масса не изменилась (корм застрял) | Владелец получает уведомление об ошибке |
| **6. Синхронизация** | При наличии Wi-Fi журнал отправляется на сервер | История доступна в приложении |
